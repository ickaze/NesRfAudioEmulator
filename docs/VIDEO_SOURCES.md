## 読み込み

MP4 / H.264 8bit YUV420 / AACの組み合わせが基本です。拡張子だけでは対応は決まりません。
Windows Media Foundationでデコードできるローカル動画をF4の動画ウインドウで開きます。
720p程度で十分です。最終的な混信用映像は256×240へ変換されます。
自動ループは有効です。上/下隣接、映像混信、音声混信の量を調整し、メインをRF出力にしてください。
